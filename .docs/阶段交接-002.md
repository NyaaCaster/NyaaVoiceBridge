# NyaaVoiceBridge V1 阶段交接 002 (P2 收尾)

## 交接目的
记录 P2 阶段（硬件与核心协议驱动）的研发成果，准备推进 P3（macmini 部署与 Systemd 守护上线）。

## 当前进度
- ✅ P1 基础工程化、Git 仓库初始化与 SSOT 蓝图
- ✅ P2 硬件与核心协议驱动：
  - `src/config.py`：YAML 配置解析与验证
  - `src/audio.py`：PipeWire 录放音封装与 `bt-audio-setup.sh` 蓝牙自愈集成
  - `src/stt.py`：SenseVoice OpenAI-compatible HTTP 客户端
  - `src/astrbot.py`：OneBot V11 反向 WebSocket 客户端（完整支持握手、心跳、TTS 语音段提取与解析）
  - `src/vad.py`：基于分贝能量计算的自适应 VAD 静音切片检测器
  - `src/service.py`：核心业务协调调度器与防自激状态保护
  - `src/main.py`：CLI 入口（支持单次测试与常驻后台双模式）
