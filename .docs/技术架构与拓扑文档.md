# NyaaVoiceBridge 技术白皮书与架构全景解析

> **版本**：v1.0.0  
> **定位**：连接物理边缘蓝牙音频终端与 AstrBot 智能体核心的局域网独立低延迟全双工语音桥接系统。  
> **适用对象**：开源社区开发者、智能硬件折腾者、Bot 插件与 Agent 架构师。

---

## 📖 概述与设计哲学

在构建个人/家庭物理 AI 实体（如智能音箱、桌面桌面陪伴机器人）时，传统方案通常依赖商业云端音箱（如小爱音箱、天猫精灵）做二次反代，或通过 QQ 机器人框架（如 NapCat/Lagrange）配合官方聊天通道转发。这往往面临：
1. **云端风控与封号风险**：高频语音交互极易触发社交平台封禁。
2. **高延迟与双重网络跳点**：音频需要在公网云服务器与本地边缘设备之间多重中转。
3. **生态割裂与人格丢失**：外挂语音通道往往无法无损读取 AstrBot 机器人的画像、长期记忆库（RAG/KB）、身份认知及下挂扩展工具。

**NyaaVoiceBridge** 采用全新设计思想：**“硬件透明抽象 + 协议无缝契合 + 全域智能体共鸣”**。
通过 Linux 下现代音频子系统 PipeWire 捕获物理音箱麦克风流，经由局域网内部署的极速 SenseVoice 模型完成 STT，以标准 OneBot V11 反向 WebSocket 协议伪装为原生终端直通 AstrBot，100% 激活下挂的猫猫全套智能体系，并把 TTS 语音回灌播放，实现硬件与灵魂的彻底合一。

## 🧩 核心子系统剖析

### 1. 物理音频与蓝牙 HFP 通道
- **HFP (Hands-Free Profile) 双向流**：小米等蓝牙音箱通常在 A2DP 模式下仅支持播放，无法录音。本方案通过 `bt-audio-setup.sh` 脚本在 PipeWire 中强制切换至 HFP 模式，建立同时包含 Sink 与 Source 的全双工音频流。
- **48kHz 采样重对齐**：经深入验证，现代端到端识别模型（如 SenseVoice）对下采样敏感，网桥使用 48kHz 采样率长连接，杜绝采样率衰减造成的字音丢失。

### 2. 常驻管道流与防吞字环形 VAD
- **管道缓存自适应**：传统每次发音临时启动录音进程的方式会遇到 Linux 标准管道缓冲滞后及 PipeWire 握手抖动，导致前半秒发音被腰斩。
- **1000ms Pre-buffer**：网桥维持一条常驻 `pw-record` 标准输出管道，在未检测到说话时维护 1 秒内存滑动窗口；当音量突增突破能量门限（如 `-40.0 dBFS`）时，自动将前 1 秒的起音拼接回完整语音段，彻底避免吞掉唤醒词首字。

### 3. OneBot V11 反向协议无缝对接
- **身份标识绑定**：网桥向 AstrBot 发送 WebSocket 消息时，显式构造 `sender: {"user_id": <USER_ID>}`。AstrBot 根据该 ID 精准调取对应主人的长期记忆、会话画像与专属称呼。
- **语音标识注入**：在下发的消息体中附加合法的 Base64 微音频段，精准触发 AstrBot `astrbot_plugin_nyaa_voice` 的 `on_llm_request` 钩子，指示智能体使用语音进行回复。
- **超大载荷支持**：TTS 生成的 Base64 报文体积可达数兆字节，客户端通过扩大 WebSocket `max_size` 至 32MB，规避 RFC 1009 消息超限错误。

### 4. 猫猫智能框架与记忆回流
- **人格与情感（`astrbot_plugin_nyaa_prompt`）**：在 LLM 调用前动态注入猫猫当前的心情状态、亲密度等级与个性化语气后缀。
- **全智能调度（`astrbot_plugin_nyaa_IntelligenceFrame`）**：作为整个智能体的反射与派工神经中枢，协调外部工具链与执行器。
- **长短期记忆提炼（`NyaaLibrary-MCP` + `Memory Writer`）**：每一轮通过物理音箱发生的自然对话，都会在对话达到阈值时自动触发记忆提炼服务，沉淀为知识库档案，下次对话即可无缝唤醒回忆。

## 🛠️ 社区二次开发与扩展指引

### 如何新增其他麦克风或外置声卡？
在 `config/config.yaml` 中修改 `device:` 字段：
```yaml
device:
  # 通过 pw-cli list-objects Node 查询您的系统设备节点名
  input_node: "alsa_input.usb-Your_Mic_Device.mono-fallback"
  output_node: "alsa_output.usb-Your_Speaker_Device.stereo-fallback"
  sample_rate: 48000
```

### 如何接入其他第三方 STT？
网桥内置标准 OpenAI `/v1/audio/transcriptions` 接口，支持 Whisper、Faster-Whisper、SenseVoice-API 或商业 API，只需变更 `stt.api_base` 即可无缝替换。
