# NyaaVoiceBridge V2 移动端方案 阶段交接 003

## 交接目的
本文件记录 V2-P3（SenseVoice STT 异步转写与唤醒词过滤引擎）阶段的完成情况与架构成果，为后续 V2-P4（AstrBot OneBot V11 反向 WS 通道与 TTS 互斥播放）提供标准交接依据。

## 当前进度
- [x] V2-P1：Android 原生工程初始化与 TUI 控制台骨架
- [x] V2-P2：原生音频采集、蓝牙 SCO 路由与 RMS VAD 引擎
- [x] V2-P3：SenseVoice STT 异步转写与唤醒词过滤引擎
- [ ] V2-P4：AstrBot OneBot V11 反向 WS 通道与 TTS 互斥播放
- [ ] V2-P5：前台保活服务、全域容灾演练与真机打包发布

## 本轮已实现
1. `SenseVoiceClient.kt`：
   - 基于 OkHttp 4 的高能效异步 Multipart/form-data 音频上传；
   - 支持动态 JSON 解析、富文本音效标签（`<|zh|><|NEUTRAL|>...`）清洗与智能异常重试机制。
2. `WakeWordDetector.kt`：
   - 完整移植 Linux 端高精度的多方言/同音字/谐音模糊容错正则匹配引擎；
   - 支持空载荷问答与直接带指令的连续问答识别；
   - 内置连续多轮会话上下文计时器（15秒内免唤醒持续对讲）。
