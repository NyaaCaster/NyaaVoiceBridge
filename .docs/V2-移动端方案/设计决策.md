# NyaaVoiceBridge V2 移动端方案 - 设计审核与关键决策 (已拍板)

## 一、 用户核心诉求与边界拍板

1. **平台与形态**：
   - 暂不支持 iOS，专注 Android 平台。
   - 目前不搞复杂 GUI，仅需一个最简极客控制台（TUI / Log Console），能够实时显示音频状态、VAD 触发、STT 转写及 WebSocket 连接与交互日志。
2. **核心业务灵魂：无手机盲操（真正的随身耳语）**：
   - **坚决不做屏幕长按等任何 UI 手工操作**。App 启动后即沉浸于后台。
   - 依托用户随身佩戴的无线/蓝牙耳机，全程靠纯语音触发词 **`小猫同学`** 进行无感唤醒对话。手机无需掏出口袋，实现如同电影《Her》般的随身耳语交互。
3. **技术栈重估与最终定案：原生 Android (Kotlin)**：
   - **绝对核心指标**：**后台保活机制（Foreground Service + WakeLock + 电池白名单）** 与 **蓝牙 SCO 模式自动激活（`AudioManager.startBluetoothSco()`）**。
   - 作为 Google 官方体系首选的原生 Kotlin，在处理 Android 系统层深度的后台音频采集生命周期、蓝牙广播监听（`ACTION_SCO_AUDIO_STATE_UPDATED`）、系统底层前台通知服务方面拥有无可比拟的掌控力与最轻的运行时资源消耗。彻底排除 Flutter 的中间层插件封装黑盒。
4. **网络通信环境**：
   - 采用现有 macmini 的 Nginx 反代网络架构。
   - 已打通 AstrBot 公网反代访问（`http://h.nyaa.host:6185`）。
   - 若链路上强制要求 HTTPS/WSS 加密通道，利用 macmini 上既有的 Nginx 代理与证书机制进行端口映射与安全承载。

## 二、 关键决策结论记录表

| 决策维度 | 最终选型 | 拍板理由 |
|---|---|---|
| **开发语言与工程结构** | **原生 Android (Kotlin + Gradle)** | 保障后台常驻绝对不被杀、蓝牙 SCO 录放音硬件路由精准接管，无 Flutter 中间层损耗。 |
| **界面展示风格** | **极简暗黑控制台 (Terminal / TUI Console)** | 仅提供核心服务开关、配置项、以及实时高刷滚动的全链路诊断日志，开发成本极低且纯粹高效。 |
| **交互与触发机制** | **纯唤醒词「小猫同学」盲操监听** | 拒绝任何屏幕手工干预。手机放在口袋/包内，用户戴着耳机直接说“小猫同学，...”，自动闭环对话。 |
| **防自激互斥机制** | **播放态硬件与软件双重互斥锁** | 收到 TTS 播放时立即暂停 VAD 采集，播放完成后延迟 500ms 重启监听，防止耳机漏音或外放声音形成回音环路。 |
| **网络通道策略** | **macmini Nginx 反向代理链路** | 复用现有稳定公网通道（`h.nyaa.host:6185` 等），必要时配置 Nginx SSL/WSS 反代。 |

## 三、 Android 端核心技术实现蓝图

### 1. 随身保活与生命周期设计
- **`VoiceBridgeForegroundService`**：
  - 注册 `android:foregroundServiceType="microphone|connectedDevice"`（兼容 Android 14+ 严格要求）。
  - 常驻通知栏显示当前连接状态（如：`🟢 监听中 (小猫同学)` / `🗣️ 正在对话`）。
  - 申请 `PARTIAL_WAKE_LOCK`，防止手机锁屏进入 Deep Sleep 导致麦克风采集被系统挂起。

### 2. 蓝牙耳机 SCO 无感无缝路由
- 注册 `BluetoothHeadset` 与 `AudioManager` 广播。
- 当检测到蓝牙耳机连接时，自动触发：
  ```kotlin
  audioManager.mode = AudioManager.MODE_IN_COMMUNICATION
  audioManager.startBluetoothSco()
  audioManager.isBluetoothScoOn = true
  ```
- 确保用户的呼唤精准由蓝牙耳机麦克风捕获，回复声音精准推入耳机，绝不产生物理外放尴尬。

### 3. 轻量 VAD 能量检测与流转
- 端侧只做超低功耗的 RMS（均方根能量）滑窗检测（`16kHz / 48kHz, 16bit PCM`）。
- 检测到人声后切片打包为标准 WAV 内存流，异步 POST 至 SenseVoice 服务。
- 文本返回后进行唤醒词匹配：
  - 若包含“小猫同学”等，剔除唤醒词，将净意图通过 WebSocket 发送给 AstrBot。
  - 若为纯唤醒词，直接在端侧播报“你好呀”或请求 AstrBot 打招呼。
