## 本轮已实现核心代码资产
1. **`WavUtils.kt`** (`com.nyaa.voicebridge.audio.WavUtils`)：
   - 纯内存 PCM 16bit 转 RIFF/WAV 格式封装；
   - 自动计算 Subchunk 大小与头结构，零磁盘 I/O 损耗。
2. **`RmsVadEngine.kt`** (`com.nyaa.voicebridge.audio.RmsVadEngine`)：
   - 低功耗滑动 RMS 能量监测，规避重型神经网络 VAD 带来的手机发热；
   - 具备 600ms 预滚环形缓冲（Pre-speech Buffer），确保「小猫同学」等唤醒词头部首字完整无损；
   - 800ms 静音判定切片结束，支持 0.5s~15s 语音段动态切割。
3. **`BluetoothScoManager.kt`** (`com.nyaa.voicebridge.audio.BluetoothScoManager`)：
   - 拦截 `ACTION_SCO_AUDIO_STATE_UPDATED` 广播，全自动接入随身 TWS 耳机麦克风；
   - 自动切换 `MODE_IN_COMMUNICATION`，确保锁屏息屏状态下耳麦硬件常开。
4. **`AudioRecordDriver.kt`** (`com.nyaa.voicebridge.audio.AudioRecordDriver`)：
   - 基于 Kotlin 协程调度，在 `Dispatchers.IO` 线程运行 48kHz 单声道低延迟采集；
   - 连通 VAD 引擎，输出标准化 WAV 字节流并回调给服务层。
