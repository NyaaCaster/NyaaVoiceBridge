## 本轮（V2-P5）追加与核心实现成果

1. **Android 系统下拉状态栏快捷开关 (`VoiceBridgeTileService.kt`)**：
   - 继承自 `android.service.quicksettings.TileService`；
   - 注册了 `android.permission.BIND_QUICK_SETTINGS_TILE` 与意图过滤器 `android.service.quicksettings.action.QS_TILE`；
   - **用户体验**：无需点开 App 界面，手机下拉控制中心（与 WiFi、蓝牙、手电筒并列）直接出现「**猫猫耳语**」快捷图标；
   - **实时联动**：点击即刻一键启停后台常驻监听服务，并在磁贴副标题实时指示“小猫同学监听中”或“点击开启”。
2. **最高优先级后台保活矩阵 (`VoiceBridgeService.kt`)**：
   - 常驻前台通知：`startForeground` + `FOREGROUND_SERVICE_TYPE_MICROPHONE`；
   - 锁屏防止休眠锁：`PowerManager.PARTIAL_WAKE_LOCK` 自动获取与注销，确保手机揣在兜里、黑屏息屏时 CPU 音频通道不断；
   - 蓝牙 SCO 路由保活：`BluetoothScoManager` 接管耳麦通信，配合无感盲操。
3. **全链路容灾流转闭环**：
   - 随身手机正常接入时：蓝牙耳麦拾音 -> SenseVoice -> AstrBot -> 本地耳机流利播报；
   - 手机离线/耳机断开时：触发全域智能体容灾，AstrBot 自动通过 NapCat 将语音切片发送到绑定的 QQ 私聊窗口，消息绝不落地。

## 编译与 APK 构建指引

工程已置于 `H:\GitHub\NyaaVoiceBridge\android\`，支持标准 Gradle 编译：
```bash
cd H:\GitHub\NyaaVoiceBridge\android
# 构建 Debug 版 APK
./gradlew assembleDebug

# 产物路径：app/build/outputs/apk/debug/app-debug.apk
```
安装到手机后：
1. 首次打开 App，在极简配置框中确认 `ws://h.nyaa.host:6185/ws` 与 STT 地址并保存；
2. 下拉手机状态栏，点击编辑快捷磁贴，将「**猫猫耳语**」拖入常驻开关栏，即可实现日常随时无感盲操！
